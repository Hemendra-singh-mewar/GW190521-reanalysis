# Publication status

Updated on 4 October 2026.

- GitHub: [version 0.2.2](https://github.com/Hemendra-singh-mewar/GW190521-reanalysis/releases/tag/v0.2.2) is published with the complete project ZIP, methods note and LaTeX source bundle.
- Verification: all 62 release files were checked, including extracted PDF text and metadata. The eight-page PDF was rebuilt and visually inspected, and the standalone LaTeX bundle compiled successfully. Notebook code cells and outputs were preserved.
- Author: Hemendra Singh. The work was carried out in 2024 at the Gravity Exploration Institute, School of Physics and Astronomy, Cardiff University. The public implementation and methods note were subsequently reconstructed and revised from that project.
- Zenodo: the three corrected release files are publicly archived at [10.5281/zenodo.23119422](https://zenodo.org/records/23119422).
- arXiv: paused at the author's request. The source package is prepared, but no submission has been completed and no arXiv identifier has been issued. Endorsement is required before submission can proceed.
- Distribution cleanup: obsolete releases and tags v0.2.0 and v0.2.1 were removed. The v0.2.2 tag now points to the clean snapshot `53038c4c7e26e5f566b8b6a90bbaf9a15b81c1c5`, with the same validated file tree and release assets. Earlier Git commit links are no longer part of the maintained history.

The archived release remains unchanged. Subsequent repository documentation
records its verified DOI and current submission status.

The manuscript makes a restricted methods contribution. It does not provide
astrophysical posteriors, a false alarm probability or a Bayes factor. The
computational validation is documented in `validation_report.md`; the additional
work needed for source inference is described in `research_roadmap.md`.
