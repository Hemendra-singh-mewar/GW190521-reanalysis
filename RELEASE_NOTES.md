# Version 0.2.0

This release provides a corrected, reproducible methods study of GW190521.

- Restores the physical reference time of padded time-domain waveforms.
- Applies detector arrival delays to frequency-domain templates.
- Replaces the ambiguous network summary with independent-peak, common-time
  and fixed-response coherent quantities.
- Uses quality screened off-source PSDs throughout the analysis and plots.
- Defines the sine Gaussian Q convention and evaluates a 494-shape grid.
- Adds 11 regression cases, 384 conditional Gaussian-noise amplitude trials,
  sensitivity checks and a complete data/software provenance record.
- Includes a clean notebook, HTML preview, figures and an eight-page methods note.

The earlier development burst SNR near 5.1 is superseded. This release contains
no astrophysical parameter posterior, Bayes factor or detection significance.
